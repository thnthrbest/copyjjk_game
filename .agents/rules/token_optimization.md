# Token Optimization & Agent Performance Guidelines

- **Concise Responses**: Avoid intro/outro pleasantries or filler words.
- **Targeted Edits**: Modify only exact target lines rather than rewriting full files.
- **Targeted File Reading**: Use `StartLine` and `EndLine` when reading large files.
- **Context Reuse**: Do not re-read files or re-run logs if they are already in the context.
- **Brief Summaries**: Limit turn summaries to 1-2 bullet points.
